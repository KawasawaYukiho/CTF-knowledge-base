# USB HID 键盘流量

> **所属分类**：Misc ｜ **难度参考**：中等
> **适用题型**：给出一串 `xx:xx:xx:...` 的 8 字节十六进制报文（USB 键盘抓包），要求还原"敲了什么键"，并常结合 Vim/编辑器操作走迷宫出结果。

## 一、知识点原理讲解

### 1. USB HID Boot 键盘报文格式

USB 键盘的中断传输报文固定 **8 字节**：

| 字节偏移 | 含义 |
| --- | --- |
| Byte 0 | 修饰键（Ctrl/Shift/Alt/Gui，位掩码） |
| Byte 1 | 保留位（恒 0） |
| Byte 2 ~ Byte 7 | 按键 Usage ID（最多同按 6 键） |

实际抓包往往每个报文只有 Byte2 非零（每次只按一个键），且"按下"与"释放"成对出现（释放即全 0）。因此只取**第 3 个字节（Byte2）**作为按下的 Usage ID 即可。

### 2. Usage ID → 字符映射（Boot 协议常用子集）

注意 Usage ID **不是 ASCII 码**，必须查 USB HID Usage 表：

```text
0x04 a  0x05 b  0x06 c  0x07 d  0x08 e  0x09 f
0x0a g  0x0b h  0x0c i  0x0d j  0x0e k  0x0f l
0x10 m  0x11 n  0x12 o  0x13 p  0x14 q  0x15 r
0x16 s  0x17 t  0x18 u  0x19 v  0x1a w  0x1b x
0x1c y  0x1d z
0x28 Enter   0x2c Space   0x29 Esc
```

### 3. 找"模式切换点"切段，再模拟终端操作

整条按键序列里通常藏一个明显的模式切换键（如 `0x29` Esc）。把序列在它处一分为二：

- **前段**：先按 `i` 进入编辑器**插入模式**，随后敲出一个网格（如 5×5 字母矩阵，每 5 个字母一个 Enter 换行、中间夹 Space）。去掉开头那个插入命令，正好 25 个字母排成 5×5。
- **后段**：回到**普通模式**，按方向键移动光标（Vim 里 `h`=左、`j`=下、`k`=上、`l`=右）。

### 4. 模拟光标走迷宫

起点通常在矩阵一角（如左上角）。把每步合法落在矩阵里的字符依次记下（**起点字符也要计入**），越界移动不产生新字符。连续一堆 `k`/`h` 往往是把光标一路顶到角落的"复位"操作，真正的路线是后面变化的 `j`/`l`。

## 二、通用解题思路 / 套路

```
拿到一串 8 字节十六进制报文
  → 取 Byte2 的 UsageID，按 HID Usage 表映射成字符
  → 在 0x29(Esc) 或明显模式切换键处切两段
  → 前段去掉开头插入命令，还原出字母网格
  → 后段把方向键映射成 (dx,dy)，从起点模拟光标
  → 记录途经字符（含起点）→ 拼接得结果
```

- 背下 Boot 协议 UsageID 表（至少 a–z、Enter、Space、Esc）。
- 别把矩阵里的字母误当插入命令——插入命令只在最开头出现一次。
- UsageID 是 `0x0d`=j、`0x0b`=h、`0x0e`=k、`0x0f`=l，**不能用 ASCII 码对应**。
- 越界移动不采集字符，别把复位步数也算进路径。

## 四、实战例题

### 例题 1：USB 键盘报文还原 5×5 字母矩阵，模拟 Vim 光标走迷宫

- 题型特征：一行行 `00:00:xx:00:...` 的 8 字节十六进制，题面提"键盘/USB/打字"。
- 解题思路：只取每行第 3 个字节作为 UsageID，按 HID 表映射字符；在 `0x29`(Esc) 处切两段——前段去掉开头的插入命令 `i`，正好 25 个字母排成 5×5 矩阵；后段是 Vim 普通模式方向键，先连续 `k`/`h` 把光标顶到左上角（越界不算字符），随后 `j`/`l` 走迷宫，从起点（左上角）开始记录每步落在矩阵里的字符，拼接即结果。
- 关键工具/脚本：`script/USBHID键盘流量/solve.py`（自动完成解析、矩阵还原与光标模拟）、同目录 `usb_data.txt`（原始 HID 报文）。
- 结果：得到 flag。
