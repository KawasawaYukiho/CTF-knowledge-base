# GIF 拆帧与帧拼接

> **所属分类**：Misc ｜ **难度参考**：简单
> **适用题型**：一张 GIF 动图，切换时似乎有文字/字幕一闪而过。

## 一、知识点原理讲解

### 原理
GIF 通过连续播放多张帧形成动画。隐写题会把结果的几段文字**分别画在不同帧上**——单看每一帧都只是片段，按时间顺序连起来才是完整内容。正常播放时片段一闪而过，肉眼难拼；拆帧后逐张浏览就能逐段记录。

### 拆帧本质
GIF 是多帧容器（类似多页文档），可以逐帧导出为独立 PNG。同理，APNG、WebP 动图、多页 TIFF 都是"拆开逐页/逐帧看"。

## 二、通用解题思路 / 套路

```
拿到 .gif 动图，切换时有文字一闪而过
→ 用拆帧工具导出全部帧为 PNG
→ 按文件名顺序逐帧浏览
→ 记下出现文字片段的帧号与文字
→ 按帧号从小到大把片段拼接
```

易错点：
- 别只看默认首帧；
- 帧顺序按编号，别按视觉印象乱拼；
- 注意透明叠加帧可能把片段盖在底图上。

## 三、工具使用

| 工具 | 安装 | 常用命令 / 参数 | 输出解读 |
| --- | --- | --- | --- |
| ImageMagick | Kali 自带 | `convert x.gif frame-%02d.png` | 全部帧导出 |
| Python Pillow | `pip install pillow` | `im.seek(i); im.save(...)` | 逐帧保存 |
| ezgif / 7-Zip | 在线 / 自带 | 在线拆帧或把 gif 当压缩包打开 | 预览各帧 |

```python
from PIL import Image
im = Image.open("x.gif")
for i in range(im.n_frames):
    im.seek(i); im.save(f"frame-{i:03d}.png")
```

## 四、实战例题

### 例题 1：动图不同帧上散落着文字片段
- 题型特征：一个约数 MB 的 GIF 动图，体积远大于单帧图，播放时似乎有字幕闪过。
- 解题思路：用 ImageMagick 或 Pillow 把全部帧导出为 PNG，按编号顺序逐张浏览，发现若干帧上分别写着结果的文字片段，按帧号从小到大把片段首尾相接拼出完整内容。
- 关键工具/脚本：Pillow 逐帧导出脚本（见上；本题原帧图均含文字片段，此处仅以方法描述）。
- 结果：按帧序拼出 flag。
