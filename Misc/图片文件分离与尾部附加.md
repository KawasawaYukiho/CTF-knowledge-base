# 图片文件分离与尾部附加数据

> **所属分类**：Misc ｜ **难度参考**：简单
> **适用题型**：图片体积异常偏大、命名随意；或一张图解到一半发现后面还粘着别的文件。

## 一、知识点原理讲解

### 原理：格式有"结束标志"，之后的数据被无视
图片格式都有明确的结束标记，查看器只解码到该标记为止，**其后追加的数据严格来说不属于图片，但仍躺在文件里**：

| 格式 | 结束标记 | 之后可追加内容 |
| --- | --- | --- |
| JPEG | `FF D9`（EOI） | 明文、ZIP、另一个文件 |
| PNG | `IEND` chunk（含 `49 45 4E 44`） | WAV、ZIP、其他文件 |

把多个文件按文件头/文件尾特征直接拼在一个载体里（append 拼接或 carving 内嵌），就形成"一张图里藏另一个文件"。当一张图片体积异常大（如 7.9MB 的 PNG），优先怀疑尾部或内部拼了东西。

### 两种隐藏方式
1. **尾部 append**：在 `FF D9` / `IEND` 之后直接粘另一个完整文件。用十六进制编辑器定位结束标记后切开即可。
2. **内嵌 carving**：多个文件按签名交错/拼接在一个载体里，需要按文件头特征重新切分（carving）。

### 关键边界
- 附加数据在 `FF D9`/`IEND` **之后**，切开时不要误删图片本体；
- 尾部拼的可能是 ZIP/WAV/图片，分离后要按各自类型继续分析。

## 二、通用解题思路 / 套路

```
图片体积偏大 / 命名随意
→ 先 binwalk 看内嵌了哪些签名
→ 十六进制编辑器定位结束标记（FF D9 / IEND）
→ 标记之后的数据另存，按文件头（PK、RIFF/WAVE…）判断类型
→ 是 ZIP 走 ZIP 流程，是 WAV 上 Audacity 频谱图
→ 交错内嵌的用 foremost 按签名批量 carving
```

易错点：
- 只看图片预览看不出异常，必须翻文件尾或跑 binwalk；
- carving 时要按文件头签名切，别凭肉眼估偏移；
- 分离出的音频/压缩包要继续下游分析，不是终点。

## 三、工具使用

| 工具 | 安装 | 常用命令 / 参数 | 输出解读 |
| --- | --- | --- | --- |
| binwalk | Kali 自带 / `sudo apt install binwalk` | `binwalk img.jpg`、`binwalk -e img.jpg` | 列出内嵌签名；`-e` 自动提取 |
| foremost | Kali 自带 | `foremost -i img.jpg -o out` | 按文件头签名批量 carving 到 out 目录 |
| 010Editor / HxD | 官网 | 搜 `FF D9` / `IEND` / `50 4B` | 手工切开尾部附加数据 |

foremost 切包审计示例（对一张 2.4MB JPG 的 carving 结果）：

```text
Num  Name             Size    File Offset
0:   00000000.jpg    252 KB   0
1:   00001172.jpg    166 KB   600325
2:   00000504.zip      2 MB   258300
3:   00000505.png    333 KB   258668
4:   00001506.png    740 KB   771234
jpg:2  zip:1  png:2
```

> 完整审计记录见 `script/图片文件分离与尾部附加/foremost_audit.txt`。

## 四、实战例题

### 例题 1：JPEG 在 EOI 之后追加一段 ASCII 明文
- 题型特征：给一张值班照片 JPG，题目暗示"图里另有内容"。
- 解题思路：JPG 以 `FF D9` 结束，用十六进制编辑器滚到文件末尾，发现在 `FF D9` 之后还粘着一段 ASCII 明文，切出该段即得一个 flag 片段。
- 关键工具/脚本：`../assets/images/图片文件分离与尾部附加/room_photo.jpg`（已剥离尾部片段的干净 JPG 载体，用于示意载体外观）。
- 结果：得到一个 flag 片段。

### 例题 2：一张超大 PNG 尾部拼了一段 WAV 音频
- 题型特征：PNG 体积明显偏大（数 MB），预览却正常。
- 解题思路：PNG 由一串 chunk 组成、以 `IEND` 结束；在 010Editor 里定位 `IEND`，其后的数据另存为 `.wav`，前半段另存为干净 PNG；分离出的音频再上 Audacity 频谱图读内容。
- 关键工具/脚本：`binwalk -e` 自动切分尾部附加文件。
- 结果：分离出音频并解出隐藏信息。

### 例题 3：一张人物大图里 carving 出多个内嵌文件
- 题型特征：多张人物图，其中一张明显偏大，题面提到"切开/锁"。
- 解题思路：`binwalk` 扫描后用 `foremost -i 图.jpg -o out` 按签名批量切出 2 个 jpg、1 个 zip、2 个 png；切出的 zip 再走 ZIP 流程（伪加密/口令）。
- 关键工具/脚本：`script/图片文件分离与尾部附加/foremost_audit.txt`（foremost 对该载体的切包审计记录，列出各文件偏移与尺寸）。
- 结果：carving 出嵌套压缩包并继续解压。
