# 进制与编码转换

> **所属分类**：Crypto ｜ **难度参考**：入门
> **适用题型**：HTML 实体编码还原、多进制数字字面量混排识别、ASCII 码拼接类入门编码题

## 一、知识点原理讲解

### 1.1 HTML 数字实体编码

网页在传输和显示特殊字符时，常用数字实体表示：`&#十进制码;` 或 `&#x十六进制码;`。例如 `&#56;` 对应字符 `8`，`&#x3A;` 对应冒号 `:`。这种编码把每个字符变成一个数字加括号的形式，题目经常把整串内容用实体编码包裹一层。

Python 标准库 `html.unescape()` 可以一次性把整串实体还原成普通字符，无需手动逐个替换。

### 1.2 多进制数字字面量与 `int(s, 0)` 自动识别

解码后常得到一串用空格分隔的"数字字面量"，它们可能混排三种进制：

- **十进制**：裸数字如 `56`、`99`。
- **八进制**：`0o` 前缀如 `0o52`，或老式前导零写法。
- **十六进制**：`0x` 前缀如 `0x63`。

Python 的 `int(s, 0)` 是核心技巧：第二参数传 `0` 时，解释器会根据字符串前缀自动判断进制——`0x` 开头按十六进制、`0o` 开头按八进制、无前缀按十进制。一行就能把每个字面量统一转成整数。

### 1.3 ASCII 码还原成文本

每个整数即一个 ASCII 码（0~127），用 `bytes(iterable_of_ints)` 可以直接拼成字节串，再 `.decode()` 得到可读文本。常见可打印范围是 32（空格）~126（`~`）。

## 二、通用解题思路 / 套路

```
识别特征（满屏 &#数字; → 先 HTML 实体解码；解码后看到 0x/0o/裸数混排 → 多进制字面量题）
→ 第一步：html.unescape 剥掉实体层
→ 第二步：split 按空格切分独立数字
→ 第三步：逐个 int(x, 0) 自动识别进制转整数
→ 第四步：bytes(...) 拼接成字节串，decode 得文本
→ 观察文本形态（英文句子/格式串），提取目标内容
```

**易错点清单：**

- `int` 的第二参数必须是 `0` 才会自动识别进制；写死 `10` 或 `16` 会直接报错或结果错误。
- 提交前注意格式里夹带的多余空格（如前缀和花括号之间多了空格，要删掉）。
- 多层编码套娃题，每脱一层就观察数据形态，再决定下一层用什么工具。

## 三、工具使用

| 工具 | 安装 | 常用命令 / 参数 | 输出解读 |
| --- | --- | --- | --- |
| Python `html` 标准库 | 内置 | `html.unescape(raw_str)` | 把 HTML 实体串还原为普通字符串 |
| Python `int()` | 内置 | `int(s, 0)` — 第二参数传 0 自动识别进制 | 输入字面量字符串，输出对应整数 |
| Python `bytes()` | 内置 | `bytes(iterable_of_ints)` | 整数列表直接拼成字节串 |

典型代码块：

```python
import html

raw = "&#56;&#57; ..."   # 题目给的 HTML 实体长串
decoded = html.unescape(raw)
parts = decoded.split()
result = bytes(int(p, 0) for p in parts)
print(result.decode())
```

## 四、实战例题

### 例题 1：HTML 实体包裹多进制数字字面量的编码题

- 题型特征：一整串全是 `&#数字;` 形式的 HTML 实体，看不出直接含义。
- 解题思路：先用 `html.unescape` 剥掉实体层，得到空格分隔的多进制数字串；再用 `int(x, 0)` 自动识别每个数字的进制，统一转成 ASCII 码整数；最后 `bytes` 拼接成一句英文，句中即 flag。
- 关键工具/脚本：`script/进制与编码转换/test.py`（HTML 实体解码 + `int(x,0)` 多进制还原 ASCII）。
- 结果：得到 flag。
