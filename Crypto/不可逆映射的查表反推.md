# 不可逆映射的查表反推

> **所属分类**：Crypto ｜ **难度参考**：入门
> **适用题型**：整除取整的多对一映射、"看似不可逆"的数学变换、可打印 ASCII 约束下的反查表还原

## 一、知识点原理讲解

### 1.1 为什么"整除"看似不可逆

题目常按字符 ASCII 码 `n` 做加密变换，例如：

```python
def encrypt(n):
    if n % 2 == 1:            # ASCII 为奇数
        return (5*n + 3) // 3
    else:                     # ASCII 为偶数
        return (5*n + 2) // 4
```

整除 `//` 会丢弃余数，多个不同的 `n` 可能落到同一个 `c`（多对一映射），所以"正向公式没法唯一反解"。出题人常以此为话术说"不可逆加密"。

### 1.2 约束下的反查表法

但题目明文（flag）只由**可打印 ASCII（32~126）**组成。于是不必硬解公式，直接**正向加密所有候选字符，建立映射表**：

```python
table = {}
for n in range(32, 127):
    table[encrypt(n)] = n
```

虽然整体多对一，但对落在 32~126 的 flag 字符而言，每个密文值 `c` 对应的原文是确定的。再用 `table[c]` 逐位反查即可还原明文。

**核心思想**：正向好算、反向难算时，就在"可能的输入域"上全部正向算一遍，用字典把关系存下来，再按密文查回。这是"正向函数可逆地用查表代替公式反解"的典型思路。

### 1.3 为什么这招普遍有效

CTF 密码题里所谓"不可逆"往往是话术。只要输入域被明确约束（可打印 ASCII、特定字符集、有限长度），绝大多数"加密"都能靠穷举建表还原。

## 二、通用解题思路 / 套路

```
识别特征（给一段"不可逆"的数学变换 + 密文列表 → 先别被话术唬住）
→ 第一步：确认明文输入域约束（可打印 ASCII 32~126？特定字符集？）
→ 第二步：正向加密所有候选输入，建立"密文→原文"反查表
→ 第三步：对密文列表逐位查表，拼接还原明文
→ 多对一时用 setdefault 保留可打印字符对应项，避免歧义覆盖
```

**易错点清单：**

- 多对一时用 `setdefault` 或显式选择，避免后面的字符覆盖掉前面的（本题可打印域内结果唯一，实践无歧义）。
- 范围要对齐"可打印 ASCII 32~126"，别把控制字符也收进来造成歧义。
- 密文是整数列表，不是字节串——注意数据形态。

## 三、工具使用

| 工具 | 安装 | 常用命令 / 参数 | 输出解读 |
| --- | --- | --- | --- |
| Python 字典 | 内置 | `table.setdefault(c, n)` | 建反查表，多对一时保留首个映射 |
| `chr()` | 内置 | `chr(65)` → `'A'` | 整数 ASCII 码转字符 |

典型代码块：

```python
def encrypt(n):
    if n % 2 == 1:
        return (5*n + 3) // 3
    else:
        return (5*n + 2) // 4

enc = [<题目给的密文整数列表>]

table = {}
for n in range(32, 127):
    table.setdefault(encrypt(n), n)

flag = "".join(chr(table[c]) for c in enc)
print(flag)
```

## 四、实战例题

### 例题 1：整除多对一映射的查表还原

- 题型特征：给出加密函数（按 ASCII 奇偶分两支做整除运算）和一个密文整数列表，声称"不可逆加密"。
- 解题思路：识破"不可逆"只是整除丢余数造成的假象；明文是可打印 ASCII（32~126），范围有限；正向加密 32~126 所有字符，建立"密文→字符"反查表；对密文列表逐位查表拼接，即得 flag。
- 关键工具/脚本：`script/不可逆映射查表反推/solve.py`（正向建反查表，逐位还原 flag）。
- 结果：得到 flag。
