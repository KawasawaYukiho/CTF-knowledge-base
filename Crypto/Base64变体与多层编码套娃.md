# Base64 变体与多层编码套娃

> **所属分类**：Crypto ｜ **难度参考**：中等
> **适用题型**：自定义 Base64 字母表换表、凯撒/维吉尼亚/培根等古典密码嵌套、多层编码逐层剥解

## 一、知识点原理讲解

### 1.1 标准 Base64 与换表变体

标准 Base64 字母表固定为 `ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz0123456789+/`。题目常把字母表换成自定义顺序（如键盘序 `qwertyuiop...+/`），解密时需要**先做下标映射换回标准表**，再做标准 Base64 解码。

换表映射方法：建一个字典 `idx = {c: i for i, c in enumerate(custom_table)}`，然后对密文每个字符，取出它在自定义表中的下标 `i`，替换成标准表第 `i` 个字符。

### 1.2 常见古典密码速览

多层套娃题常见的几层：

- **凯撒密码**：字母整体位移，解密即每个字母往回移 N 位（模 26）。
- **维吉尼亚密码**：多表代换，用关键词循环作为位移序列，每个字母减去对应密钥位（模 26）。
- **培根密码**：每个字母用 5 个 `A`/`B` 表示（i/j 共用、u/v 共用），解密后会只剩 A/B 两种字符，每 5 个一组查表还原成一个小写字母。

### 1.3 嵌套顺序：加密从里外包，解密从外往里剥

多层编码/密码题，**解密顺序和加密顺序相反**。如果加密是"明文 → 培根 → 维吉尼亚 → 凯撒 → Base64 → 密文"，解密就必须"密文 → Base64 → 凯撒 → 维吉尼亚 → 培根 → 明文"。顺序反了就得不到中间形态的验证信号（比如维吉尼亚解密后应该只剩 A/B）。

### 1.4 纯 Base64 连环套与 Hex 字节流转 ASCII

除了"古典密码 + Base64"的组合，还有一类更纯粹的编码连环套：

- **双层/多层 Base64 连环**：一长串字符符合 Base64 表、长度对齐 4，解一次后**结果长得还像 Base64**（还是字母数字+/=），就不要停，继续解。有时甚至连解三四层。注意补 `=` padding 再解。
- **空格分隔 Hex 字节流转 ASCII**：形如 `66 6c 61 67 7b ...` 的两位一组空格分隔序列，每组值落在可打印 ASCII 范围（32~126），就是一串 ASCII 字符的十六进制形式。用 `bytes.fromhex(s.replace(" ", "")).decode()` 直接转成可读文本。识别信号：开头出现 `66 6c 61 67 7b` 即对应常见 flag 前缀的 ASCII。

这类题的核心直觉：**解完观察结果长得像什么，决定下一层是什么编码，别解一次就以为到底了。**

## 二、通用解题思路 / 套路

```
识别特征（给密文 + 多张"密码表/参数便签" → 古典密码套娃题）
→ 第一步：观察密文字符集，若不是标准 Base64 表 → 先怀疑换表，下标映射回标准表
→ 第二步：Base64 解码（记得补 = padding，用 validate=False 容错）
→ 第三步：逐层试古典密码（凯撒 → 维吉尼亚 → 培根），每脱一层观察数据形态
→ 第四步：解密到只剩 A/B 两种字符 → 培根密码每 5 个一组查表
→ 第五步：得到内部明文，按题目规定格式包裹后提交
```

**通用原则：解完一层就观察形态——结果还像 Base64 就继续解 Base64，出现两位一组的 Hex 串就转 ASCII，只剩 A/B 就上培根。**

**易错点清单：**

- 解密顺序别弄反（加密里外包，解密外先剥）。
- Base64 要补 `=` padding 凑成 4 的倍数；用 `latin-1` 解码避免 UnicodeDecodeError。
- 培根是 i/j、u/v 合并的 24 字母表（不是 26）。
- 一层一观察：每层解密后看数据形态判断下一层是什么，别解一次就以为到底。

## 三、工具使用

| 工具 | 安装 | 常用命令 / 参数 | 输出解读 |
| --- | --- | --- | --- |
| Python `base64` 标准库 | 内置 | `base64.b64decode(s, validate=False).decode('latin-1')` | Base64 解码，容错模式忽略非法字符；可连解多层 |
| Python `bytes.fromhex()` | 内置 | `bytes.fromhex(s.replace(" ","")).decode()` | 空格分隔 Hex 字节串 → ASCII 文本 |
| 自定义换表映射 | 手写 | `''.join(std[idx[c]] for c in ciphertext)` | 自定义表 → 标准表 |
| 凯撒/维吉尼亚 | 手写 | 模 26 位移运算 | 字母回移 N 位 |

典型代码块（四层嵌套解密框架）：

```python
import base64

ciphertext = "<题目给的密文>"
custom = "<自定义 Base64 表>"
std    = "ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz0123456789+/"
idx = {c: i for i, c in enumerate(custom)}

# 第1层：Base64 换表解码
s = ''.join(std[idx[c]] for c in ciphertext)
s += '=' * (-len(s) % 4)          # 补 padding
layer1 = base64.b64decode(s, validate=False).decode('latin-1')

# 第2层：凯撒回移 N
layer2 = ''.join(chr((ord(c)-65-7) % 26 + 65) for c in layer1)

# 第3层：维吉尼亚解密（密钥循环）
key = [ord(k)-65 for k in "<密钥>"]
layer3 = ''.join(chr((ord(c)-65-key[i%len(key)]) % 26 + 65) for i, c in enumerate(layer2))

# 第4层：培根解码（每 5 个 A/B 一组查表）
```

## 四、实战例题

### 例题 1：四层古典密码嵌套套娃解密

- 题型特征：给出密文 + 自定义 Base64 字母表（键盘序）+ 凯撒位移量 + 维吉尼亚密钥，说明加密从里往外包了四层。
- 解题思路：从最外层往内剥——第 1 层把密文字符按自定义表下标映射回标准表后 Base64 解码；第 2 层凯撒回移 7 位；第 3 层维吉尼亚解密（密钥循环），解密后应只剩 A/B 两种字符；第 4 层培根密码每 5 个一组查表，还原出内部明文。
- 关键工具/脚本：`script/Base64变体与多层编码/solve.py`（四层嵌套依次解密，含 padding 修复）。
- 结果：得到 flag。

### 例题 2：双层 Base64 连环 + Hex 字节流转 ASCII

- 题型特征：开头一长串字符完全符合 Base64 表、长度对齐 4，但解一次后结果仍是一段合法 Base64，必须再解一次；第二次解出的是一行空格分隔的十六进制字节串。
- 解题思路：先对长串做两次 Base64 解码（第一次解完观察结果仍像 Base64，不停手继续解）；第二次解码得到 `66 6c 61 67 ...` 形式的 Hex 字节流；去掉空格后 `bytes.fromhex().decode()` 转成 ASCII 文本，即为 flag 内容。
- 关键工具/脚本：`script/Base64变体与多层编码/decode_b64_hex.py`（通用双层 Base64 解码 + Hex 转 ASCII 函数模板）。
- 结果：得到 flag。
