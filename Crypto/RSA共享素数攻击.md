# RSA 共享素数攻击

> **所属分类**：Crypto ｜ **难度参考**：简单
> **适用题型**：多个 RSA 模数同时出现、共用素数导致 gcd 分解、多密钥 RSA 缺陷分析

## 一、知识点原理讲解

### 1.1 攻击背景：密钥复用的致命弱点

RSA 的安全性依赖于大整数分解的困难性。但如果出题人（或系统）在生成多组密钥时**复用了同一个素数**：

```
n1 = p · q1
n2 = p · q2
```

那么 `p` 同时是 `n1` 和 `n2` 的公因子。两个数的最大公约数就是它们公共的素因子：

```
gcd(n1, n2) = p
```

于是 `q1 = n1 // p`，`φ(n1) = (p-1)(q1-1)` 全部可得，私钥 `d` 随之暴露。

**这不是 RSA 算法本身有问题，而是"密钥生成随机数复用/撞车"导致大整数分解变得平凡。** 实际运维中，这种缺陷会导致同一批生成的 RSA 证书/密钥互相可解，是需要用 gcd 批量巡检的常见事故。

### 1.2 攻击流程

```
已知 n1, n2, e, c
→ p = gcd(n1, n2)        # 共享素数直接暴露
→ q1 = n1 // p           # 分解 n1
→ φ(n1) = (p-1)(q1-1)
→ d = e⁻¹ mod φ(n1)      # 求私钥
→ m = c^d mod n1         # 解密
```

### 1.3 延伸：多密钥题的第一反应

拿到多组 RSA 模数 `n`，**第一反应就是两两求 gcd**。若 gcd 结果不是 1，就是共享素数攻击；后续还可扩展到共模攻击（同 n 不同 e）、低解密指数（Wiener）、小指数广播等攻击模式。

## 二、通用解题思路 / 套路

```
识别特征（题目同时给两个或多个 RSA 模数 n → 立刻想到常见缺陷）
→ 第一步：两两求 gcd(n1, n2)
→ 第二步：若 gcd ≠ 1，结果就是共享素数 p
→ 第三步：q1 = n1 // p，φ = (p-1)(q1-1)
→ 第四步：d = pow(e, -1, phi) 求私钥
→ 第五步：m = pow(c, d, n1)，long_to_bytes 还原明文
```

**易错点清单：**

- 是对 `n1、n2` 求 gcd，不是对密文求。
- 求出 `p` 后要用 `n1 // p` 得 `q1`，再用 `n1` 对应的 φ 和密文 `c` 解密；不要拿错模数。
- 题目给的 n 常是十六进制字符串，记得 `int(hex_str, 16)` 转换。

## 三、工具使用

| 工具 | 安装 | 常用命令 / 参数 | 输出解读 |
| --- | --- | --- | --- |
| Python `math.gcd` | 内置 | `gcd(n1, n2)` | 返回最大公约数，即共享素数 p |
| Python `pow()` | 内置 | `pow(e, -1, phi)` 求模逆元；`pow(c, d, n)` 解密 | 大整数运算 |
| PyCryptodome | `pip install pycryptodome` | `long_to_bytes(m)` | 解密结果转可读字节串 |

典型代码块：

```python
from math import gcd
from Crypto.Util.number import long_to_bytes

n1 = int("<n1 的十六进制>", 16)
n2 = int("<n2 的十六进制>", 16)
c  = int("<c 的十六进制>", 16)
e = 65537

p = gcd(n1, n2)        # 共享素数 p
q1 = n1 // p           # 分解 n1
phi = (p - 1) * (q1 - 1)
d = pow(e, -1, phi)    # 模逆元求私钥
m = pow(c, d, n1)      # 解密
print(long_to_bytes(m))
```

## 四、实战例题

### 例题 1：双模数共享素数的 gcd 攻击

- 题型特征：给出两个大十六进制模数 n1、n2，公钥指数 e=65537，密文 c，提示两模数可能共享某个素数。
- 解题思路：直接对 n1 和 n2 求 gcd，结果就是共享素数 p；用 p 分解 n1 得 q1，算 φ(n1)，求私钥 d，解密密文 c，long_to_bytes 还原明文。
- 关键工具/脚本：`script/RSA共享素数攻击/calculate.py`（gcd 求共享素数、反推私钥并解密）。
- 结果：得到 flag。
