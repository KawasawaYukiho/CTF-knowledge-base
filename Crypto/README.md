## 建议学习顺序

按"由易到难、由散到综"的顺序上手：

1. **编码打底**：进制与编码转换 —— 熟悉"一层一层剥编码"的直觉。
2. **哈希与爆破**：哈希爆破：口令与 MD5 —— 理解"哈希不可逆但小空间可枚举"，以及加盐口令破解。
3. **查表反推**：不可逆映射的查表反推 —— 建立"正向好算就建表反查"的思路。
4. **RSA 基础**：RSA 基础与私钥推导 —— 跑通标准 RSA 加解密完整链路。
5. **异或流**：XOR 异或加密与递推数学 —— 大整数快速幂 + 字节序对齐。
6. **RSA 攻击入门**：RSA 共享素数攻击 —— gcd 共享素数攻击，是 RSA 非分解攻击的第一课。
7. **古典密码套娃**：Base64 变体与多层编码套娃 —— 综合 Base64/凯撒/维吉尼亚/培根，练逐层观察。
8. **RSA 结构分析进阶**：RSA 结构分析与代数分解 —— 观察 n 的形状、代数分解，难度最高，作为收尾综合。
