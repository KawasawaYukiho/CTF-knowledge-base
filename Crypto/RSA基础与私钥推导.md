# RSA 基础与私钥推导

> **所属分类**：Crypto ｜ **难度参考**：入门
> **适用题型**：已知 p/q/e/c 的标准 RSA 解密、RSA 完整链路复现、私钥推导基础题

## 一、知识点原理讲解

### 1.1 RSA 加解密流程

RSA 是最经典的公钥密码体制：

1. **密钥生成**：选两个大素数 `p、q`，计算 `n = p × q`，欧拉函数 `φ(n) = (p-1)(q-1)`。
2. **公私钥**：选一个与 `φ(n)` 互质的小奇数 `e`（常用 65537），求模逆元 `d = e⁻¹ mod φ(n)`，满足 `e·d ≡ 1 (mod φ(n))`。公钥 `(e, n)` 公开，私钥 `(d, n)` 保密。
3. **加密**：`c = m^e mod n`。
4. **解密**：`m = c^d mod n`。

安全性依赖于：从公开的 `n` 分解出 `p、q` 在计算上不可行。一旦能分解 `n`，就能算 `φ(n)`，进而求 `d`，体系即崩。

### 1.2 模逆元与快速幂

- **模逆元**：`d` 是 `e` 在模 `φ(n)` 下的逆元，即 `e·d ≡ 1 (mod φ(n))`。Python 3.8+ 提供 `pow(e, -1, phi)` 直接求模逆元。
- **快速幂模运算**：`pow(c, d, n)` 用平方-乘算法高效计算大整数模幂，不需要真的算 `c^d` 再取模。
- **大整数转字节串**：解密得到的明文是一个大整数，需要用 `long_to_bytes(m)` 还原成可读字节串。

### 1.3 为什么这是"送分型 RSA"

当题目直接把 `p、q、e、c` 全给出来时，**不需要分解 n**——这是最基础的 RSA 入门练手，用来建立完整链路的直觉。后续所有 RSA 攻击题（共享素数、低指数、共模、Wiener 等）的终点动作都是：**一旦拿到 p、q，就回到这个标准解密流程**。

## 二、通用解题思路 / 套路

```
识别特征（题目直接给出 p、q、e、c 四个大整数 → 标准 RSA 解密入门题）
→ 第一步：n = p * q
→ 第二步：φ(n) = (p-1) * (q-1)
→ 第三步：d = pow(e, -1, phi)  求私钥
→ 第四步：m = pow(c, d, n)    解密
→ 第五步：long_to_bytes(m) 还原成明文字符串
```

**易错点清单：**

- `pow(e, -1, phi)` 要求 `e` 与 `phi` 互质；不互质会报错。
- 解密用的是 `pow(c, d, n)`，别写成 `pow(m, e, n)`。
- 大整数转字节串用 `long_to_bytes`，不是 `.to_bytes()`（后者需要指定长度）。

## 三、工具使用

| 工具 | 安装 | 常用命令 / 参数 | 输出解读 |
| --- | --- | --- | --- |
| Python `pow()` 三参数 | 内置 | `pow(e, -1, phi)` 求模逆元；`pow(c, d, n)` 快速幂解密 | 返回整数结果 |
| PyCryptodome | `pip install pycryptodome` | `from Crypto.Util.number import long_to_bytes` | 大整数 → 字节串 |

典型代码块：

```python
from Crypto.Util.number import long_to_bytes

p = <大整数素数>
q = <大整数素数>
e = 65537
c = <密文大整数>

n = p * q
phi = (p - 1) * (q - 1)
d = pow(e, -1, phi)          # 求私钥
m = pow(c, d, n)             # 解密
print(long_to_bytes(m).decode())
```
