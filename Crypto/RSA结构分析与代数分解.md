# RSA 结构分析与代数分解

> **所属分类**：Crypto ｜ **难度参考**：偏难
> **适用题型**：弱随机数生成 RSA、n 的十六进制结构异常、低熵种子攻击失败后的代数分解路径

## 一、知识点原理讲解

### 1.1 为什么要"看 n 的形状"

真随机 RSA 的 p、q 应是满位宽的随机大素数，`n = p·q` 也应是"满"的随机数。当随机数生成得太"匆忙/太弱"（如时间戳种子 + LCG 伪随机数），p、q 会退化成结构化数字，乘积 `n` 会暴露异常。

**"看 n 的形状"是 RSA 非分解攻击的第一步直觉**——低加密指数、共模、Wiener、Fermat 等攻击模式，都可以先从观察 n 的位结构入手。

### 1.2 观察 n 的十六进制分组结构

把 1024 位的 `n` 写成十六进制，每 16 个 hex 字符（=64 bit）分成一组。正常 RSA 的 `n` 每组都该是杂乱数字；如果中间出现一整段连续全零组，只在首尾附近有值，说明 p、q 是首尾有数、中间为零的结构化数字：

```
p = A·2^448 + B     （A 最高 64 位，B 最低 64 位，中间 384 位全零）
q = C·2^448 + D
```

### 1.3 展开乘积列方程

展开乘积：

```
n = A·C·2^896 + (A·D + B·C)·2^448 + B·D
```

三段可直接从 n 中切出：

| 位置 | 对应项 |
| --- | --- |
| 最高 128 位 | `A·C` |
| 中间带进位部分 | `A·D + B·C` |
| 最低 128 位 | `B·D` |

于是得到三个已知量 `AC、middle(=AD+BC)、BD`。

**求解步骤：**

1. **分解 A·C**：对 `AC` 质因数分解，枚举所有因数对，筛出两边都落在 64 位区间 `[2^63, 2^64)` 的 `(A, C)`。
2. **二次方程求 B**：由 `D = (middle - B·C)/A` 代入 `B·D = BD`，消元得一元二次方程 `C·B² - middle·B + A·BD = 0`。判别式 `Δ = middle² - 4·C·A·BD` 必须是完全平方数。
3. 还原 `p = A·2^448 + B`、`q = C·2^448 + D`，验证 `p·q==n` 且为素数，再解密。

### 1.4 低熵种子攻击 vs 结构分析

题目给的素数由 LCG（线性同余生成器）在时间戳种子窗口下生成，直觉上可以枚举种子复现 p、q。但如果拼接方式未知（字节序、拼接方向），直接枚举会失败。**真正的突破口不在复现 PRNG，而在观察 n 本身的形状。**

## 二、通用解题思路 / 套路

```
识别特征（RSA 题拿到 n 后，先 hex(n) 看一眼——出现大片连续零、或位宽远小于标称
         → p、q 是结构化/弱随机数，不是真随机大素数）
→ 第一步：把 n 按 64 位字拆开，打印每组，确认中间全零的结构假设
→ 第二步：判定 p=A·2^k+B, q=C·2^k+D，从 n 切出 AC、AD+BC、BD 三段
→ 第三步：分解 AC，枚举因数对筛出两端都是 64 位的 (A,C)
→ 第四步：对每组 (A,C) 列二次方程，判别式为完全平方 + 多重约束筛出唯一 B,D
→ 第五步：还原 p,q，反推私钥解密
```

**易错点清单：**

- 二次方程要判别式为完全平方、分子能整除、B/D 都在 64 位区间，多重过滤才能锁定唯一解。
- 切位时注意 2 的幂次（这里是 `2^448 = 2^(7·64)`）和进位（中间段的小值往往是高位乘积的进位）。
- 看到"种子窗口小 / LCG / 时间戳"先想低熵种子攻击；拼不出来就别死磕，转去分析 n 的代数结构。

## 三、工具使用

| 工具 | 安装 | 常用命令 / 参数 | 输出解读 |
| --- | --- | --- | --- |
| Python 大整数切片 | 内置 | `n >> 896`、`n & ((1<<448)-1)` | 按位切分大整数的各段 |
| `math.isqrt` | 内置 | `isqrt(disc)` 求整数平方根 | 配合 `s*s==disc` 判完全平方 |
| PyCryptodome | `pip install pycryptodome` | `inverse(e, phi)`、`long_to_bytes`、`isPrime` | 求逆元、转字节串、判素数 |

典型代码块：

```python
from math import isqrt
from Crypto.Util.number import inverse, long_to_bytes, isPrime

# 拆 n 的 64 位字，确认结构
words = []
temp = n
for i in range(16):
    words.append(temp & ((1 << 64) - 1))
    temp >>= 64
words.reverse()   # words[0] 最高位

# 切三段
AC = n >> 896
rest = n - AC * (1 << 896)
middle = rest >> 448
BD = rest & ((1 << 448) - 1)

# 分解 AC → 枚举因数对 → 二次方程求 B,D → 还原 p,q → 解密
```

## 四、实战例题

### 例题 1：弱随机数生成的 RSA 结构化分解

- 题型特征：题目给出 RSA 的 n、e、c，同时给出"用时间戳种子 + LCG 生成素数"的描述，种子窗口仅 600 种可能；但直接枚举种子拼不出 p、q。
- 解题思路：放弃复现 PRNG，转而观察 n 的十六进制分组结构——发现中间大片连续零，判定 p、q 首尾有数中间为零；从 n 切出 AC、AD+BC、BD 三段；分解 AC 得候选 (A,C)，列二次方程筛出唯一整数解 B、D；还原 p、q，反推私钥解密。
- 关键工具/脚本：`script/RSA结构分析与代数分解/solve.py`（拆 n 结构 → 分解 A·C → 二次方程求 B,D → 还原 p,q 并解密）。
- 结果：得到 flag。
