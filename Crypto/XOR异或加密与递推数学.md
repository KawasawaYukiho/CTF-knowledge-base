# XOR 异或加密与递推数学

> **所属分类**：Crypto ｜ **难度参考**：简单
> **适用题型**：递推/通项公式生成密钥流、大整数快速幂转字节、逐字节异或解密

## 一、知识点原理讲解

### 1.1 异或加密的本质

异或（XOR）是最基础的流加密：明文与密钥流逐字节异或得密文，解密时再与同一密钥流异或即还原。异或的核心性质是**自逆性**：`a ^ b ^ b = a`。因此只要能完整复现密钥流，就能解密密文。

### 1.2 从递推到闭式

题目常给一个线性递推式作为密钥生成源，例如：

```
a[0] = base
a[k] = 3 · a[k-1] + 2
```

直接递推一百万次也能算，但观察递推式可以配平成**闭式（通项公式）**：

```
a[n] = 2 · 3^(n-1) - 1
```

于是不必真的循环一百万次，一行 `key = 2*pow(3, n-1) - 1` 即可瞬间算出。

**核心思想**：遇到递推/通项公式当密钥源，先尝试化简成闭式再算，别傻递推。

### 1.3 大整数与字节序

`pow(3, 999999)` 是一个约 47 万二进制位的巨大整数，乘 2 减 1 后经 `long_to_bytes` 展开成约 19 万字节。关键在于：

- `long_to_bytes` 是**大端序**（最高有效字节在最前面）。
- 密文 `enc` 只有几十字节，用 `zip(enc, key_bytes)` 逐字节异或时，`zip` 在 enc 结束就停止——**实际只用到了密钥大整数的最高 N 个字节**。

所以根本不需要真的把全部字节都用完，只取开头那几十字节即可解出明文。

## 二、通用解题思路 / 套路

```
识别特征（题目给一个递推/通项公式当密钥源 + 一段短密文 → 数学题式异或）
→ 第一步：化简递推式为闭式（通项公式）
→ 第二步：pow 算出大整数 key
→ 第三步：long_to_bytes 转成大端字节串
→ 第四步：与密文逐字节异或（zip 自动截断到密文长度）
→ 第五步：得到明文
```

**易错点清单：**

- 指数是 `n-1` 不是 `n`，差一位整个密钥全错。
- `long_to_bytes` 大端序，密文对齐的是密钥的**高位**字节；`zip` 自动截断到密文长度。
- 异或流的破解关键永远是"把密钥流按生成规则完整复现出来"，长度/字节序对齐是成败关键。

## 三、工具使用

| 工具 | 安装 | 常用命令 / 参数 | 输出解读 |
| --- | --- | --- | --- |
| Python `pow()` | 内置 | `pow(3, n-1)` 大整数快速幂 | 百万指数也瞬间完成 |
| PyCryptodome | `pip install pycryptodome` | `long_to_bytes(key)` | 大整数 → 大端字节串 |
| Python `bytes()` + 异或推导 | 内置 | `bytes(x ^ y for x, y in zip(enc, key_bytes))` | 逐字节异或解密 |

典型代码块：

```python
from Crypto.Util.number import long_to_bytes

enc = b"<题目给的密文字节>"
n = 10**6
key = 2 * pow(3, n - 1) - 1      # 闭式：注意是 n-1
key_bytes = long_to_bytes(key)

flag = bytes([x ^ y for x, y in zip(enc, key_bytes)])
print(flag)
```

## 四、实战例题

### 例题 1：线性递推密钥流的闭式求解与异或解密

- 题型特征：给出一段短密文（约 30 字节），以及一个线性递推式描述密钥生成规则，递推步数极大（百万级）。
- 解题思路：把递推式化简为闭式幂式 `key = 2·3^(n-1) - 1`；用 Python 大整数快速幂瞬间算出 key；`long_to_bytes` 转成大端字节串；只取前 30 字节与密文逐字节异或，还原明文。
- 关键工具/脚本：`script/XOR异或加密与递推数学/solve.py`（闭式快速幂生成密钥，取高字节异或解密）。
- 结果：得到 flag。
