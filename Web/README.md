# Web 方向知识库（知识点索引）

本目录按**知识点/技术主题**组织。每个知识点一个条目，统一采用
"知识点原理讲解 / 通用解题思路·套路 / 工具使用 / 实战例题"四节结构，便于直接按知识点学习。

## 知识点索引

| 知识点 | 一句话说明 | 难度参考 |
| --- | --- | --- |
| [JWT 令牌](./JWT令牌.md) | 登录后 Cookie/Authorization 中的三段式 token，payload 为可公开解码的 Base64URL，常藏二次编码；配套注意用服务器 `Date` 头对时间戳窗口。 | 简单 |
| [SQL 注入盲注（ORDER BY / SQLite 函数绕过）](./SQL注入盲注.md) | `ORDER BY` 拼接点无回显时，用 `char()/instr()/min()/max()/group_concat()/hex()` 绕过双重黑名单，以排序反转作布尔信号逐字符提取。 | 中等 |
| [HTTP 方法覆盖](./HTTP方法覆盖.md) | 前端只能 POST 而后端要 PUT/PATCH/DELETE 时，加 `X-HTTP-Method-Override` 等请求头借 POST 通道发目标方法。 | 入门 |

## 学习顺序建议

按难度由易到难：

1. **HTTP 方法覆盖**（入门）——熟悉"方法覆盖请求头"，建立 Web 题"先读题、再试请求头"的直觉。
2. **JWT 令牌**（简单）——综合源码注释审计 + 服务器时间戳 + JWT 解码 + 嵌套编码识别，Web 入门经典组合。
3. **SQL 注入盲注**（中等）——ORDER BY 注入 + 黑名单函数绕过 + 布尔信号构造，建议在前两个知识点之后攻克。
