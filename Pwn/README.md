# Pwn 方向知识库

> Pwn（二进制漏洞利用）方向的知识点，当前处于建设中，随学习进度持续补充。
> 每个知识点按根目录 `模板.md` 的四节结构编写（原理讲解 / 通用解题思路 / 工具使用 / 实战例题）。

## 待补充知识点

| 知识点 | 技术要点 | 难度参考 |
| --- | --- | --- |
| 环境与交互基础 | nc 连接、pwntools 收发数据、检查二进制保护机制（NX / Canary / PIE / RELRO） | 入门 |
| 栈溢出 ret2win | 覆盖函数返回地址，直接跳转到后门函数或获取 shell 的地址 | 简单 |
| ret2 系列（ret2text / ret2shellcode / ret2libc） | 返回到代码段、自建 shellcode、或借助 libc 函数 | 中等 |
| Stack Canary 绕过 | 逐字节爆破或泄露 canary，再构造溢出 payload | 中等 |
| 格式化字符串利用 | `%x`/`%p` 泄露栈数据、`%n` 任意地址写 | 中等 |
| IO_FILE 利用 | 针对 FILE 结构体与 vtable 的利用 | 偏难 |

## 补充方式

1. 在本目录下新建 `<知识点名>.md`，严格按根目录 `模板.md` 的四节结构编写。
2. 解题脚本放 `script/<知识点>/`，关键截图放 `../assets/images/<知识点>/`。
3. 完成后更新本 README，把对应知识点从"待补充"表移除或补上条目链接。
