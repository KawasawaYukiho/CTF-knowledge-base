# 迷宫类逆向与路径还原

> **所属分类**：Reverse ｜ **难度参考**：中等
> **适用题型**：控制台程序要求输入一条路径/路线字符串，按位或按字符判墙；输入本身又是后续解密密钥的题。

## 一、知识点原理讲解

### 用位（bit）压缩存储迷宫

程序不直接存二维字符数组，而是把 `11×11=121` 个格子压进连续字节。坐标 `(x,y)` 对应 bit 索引 `idx = x + 11*y`，用第 `idx>>3` 个字节、第 `idx&7` 位表示该格是否为墙：

```c
bit = (map[idx>>3] ^ 0xA7) >> (idx & 7) & 1;   // 1=墙, 0=通路
```

两个细节：
- **异或常量先解密**：迷宫数据本身被 `^0xA7` 混淆过，取位前要先异或还原；
- **位索引**：`idx>>3` 定位字节，`idx&7` 定位该字节内的位。

### 输入派生密钥

这类题的关键结构：**合法路径字符串本身是后续解密的密钥输入**。程序用路径对一个初值反复做循环移位 + 异或迭代，收敛出单字节密钥 `v12`；走错路算出的密钥就是错的。

例：8 位循环右移 7 位 `ROR1(x,7)` 等价于循环左移 1 位（右移 7 = 把最高位 1 次挪到最低位）：

```python
def ror7(x):
    x &= 0xff
    return ((x >> 7) & 1) | ((x << 1) & 0xff)
```

### 多因子异或流

最终解密形如 `flag[i] = v12 ^ i ^ 密文[i+16]`，是"密钥 ^ 下标 ^ 密文"三因子异或，下标 `i` 本身也是密钥流的一部分。

## 二、通用解题思路 / 套路

```
IDA F5 读 main → 抓常量：输入长度、起点、终点、移动字符集、越界上限
→ 抄出判墙公式与地图数组地址
→ 脚本按位运算把地图打印成二维字符迷宫
→ 肉眼找起点到终点、长度正好等于要求步数的路径
→ 用路径按程序的迭代公式派生密钥
→ 按最终解密公式逐字节解出明文
```

易错点：
- `idx>>3` 与 `idx&7` 的位运算方向不要写反。
- ROR 位数等价换算（ROR7=ROL1）要在 8 位宽度内做，别溢出。
- 地图数据可能被异或常量混淆（如 0xA7），取位前先还原。
- 密钥依赖正确路径，必须先拿到正确路径再派生密钥。

## 四、实战例题

### 例题 1：一个按位存迷宫、路径派生密钥再异或解密的控制台题

- 题型特征：PE64 Console 无壳；`strlen` 要求输入正好 19 个字符，起点 `(1,1)`、终点 `(8,9)`，用 `a/d/s/w` 移动，越界上限 `>0xA`。
- 解题思路：抄出地图数组前 16 字节，按 `(byte^0xA7)>>(idx&7)&1` 还原 11×11 迷宫打印成二维图，肉眼找出从起点到终点恰好 19 步的路径；用该路径对初值 `0x42` 反复 `v12 = 前一字符 ^ ROR7(v12)` 迭代出单字节密钥；再按 `flag[i] = v12 ^ i ^ 密文[i+16]` 逐字节解出 21 字节。
- 关键工具/脚本：`script/迷宫类逆向与路径还原/map.py`（按位运算还原并打印 11×11 迷宫）、`script/迷宫类逆向与路径还原/flag.py`（用路径迭代求密钥，再三因子异或解出结果）、`../assets/images/迷宫类逆向与路径还原/die_info.png`（DIE 确认 PE64 Console 无壳）。
- 结果：解出明文，得到 flag。
