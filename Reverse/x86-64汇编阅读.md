# x86-64 汇编阅读

> **所属分类**：Reverse ｜ **难度参考**：入门
> **适用题型**：题目只给一段汇编代码（或反汇编结果），要求人脑模拟执行流程、识别分支与数据变换。

## 一、知识点原理讲解

### 核心概念

x86-64（Intel 语法）逆向阅读的本质是：**把汇编逐条翻译成执行状态，跟踪寄存器与内存的变化**。不需要写汇编，只需读懂常见指令的语义。

### 关键指令速查

| 指令 | 语义 | 等价 C |
| --- | --- | --- |
| `lea rdi, [buf]` | 取有效地址到寄存器 | `rdi = &buf` |
| `mov al, byte ptr [rsi]` | 取 `rsi` 指向的一个字节 | `al = *rsi` |
| `mov byte ptr [rdi], al` | 把 `al` 写入 `rdi` 指向处 | `*rdi = al` |
| `inc rsi / inc rdi` | 指针 +1 | `rsi++; rdi++` |
| `loop label` | `ecx--`；若 `ecx != 0` 跳到 label | `while(--ecx) goto label;` |
| `xor reg, imm` | 寄存器与立即数异或 | `reg ^= imm` |
| `cmp a, b` + `jcc` | 比较后按标志位条件跳转 | `if(a 与 b 的关系) goto label` |

### `loop` 指令的循环模型

`loop` 是 x86 里最常见的定长循环：进入前 `mov ecx, N`，循环体末尾 `loop label`。每次执行 `ecx--`，非零则回跳。因此循环次数恰好等于进入前的 `ecx` 值。

```asm
mov ecx, 19        ; 循环 19 次
loc:
    ...处理一个字节...
    inc rsi
    inc rdi
    loop loc       ; ecx--, 非零继续
```

### 恒真/恒假分支判断

逆向题常在两段数据处理之间插入一串"算术 + cmp + 条件跳转"，用来选择走哪个分支。判断方法是**手动把每个常量算到底**：

- `jne`（不等则跳）：只有两边不相等才跳；若算出来相等，这个跳转不执行。
- `jg`（大于则跳）：左边 > 右边才跳。
- 一串没有副作用的纯算术再 `cmp/jcc` 代码 = 分支选择器，手算即可预测走向。

**关键认知**：未被实际执行的分支里的数据往往是诱饵，不要拼入结果。

### 数据段的角色

汇编中用 `db 0x..` 列出的一串字节通常就是密文或半成品明文。结合前面的循环变换（如 `xor al, 0x42`）就能还原。

## 二、通用解题思路 / 套路

```
拿到汇编文本 → 建立寄存器/指针表格，逐条人脑模拟
→ 识别 "mov ecx, N + loop" = 定长循环，记下长度与变换
→ 遇到 cmp/jcc 链，手算每个常量，判定实际走向哪个分支
→ 区分执行到的分支（真实数据）与干扰分支（诱饵，丢弃）
→ 对数据段字节按循环里的变换做逆运算（XOR 自逆，直接再异或一次）
→ 拼接各段结果，末尾补 \0 → 得到输出
```

**易错点**：
- `loop` 的循环次数由进入前的 `ecx` 决定，不要数错。
- XOR 解密和加密用同一个 key（异或是自逆运算）。
- 不要把未执行分支里的字节拼进去——那是诱饵。
- 混淆常数要看准十六进制后缀（如 `42h` = 0x42，不是十进制 42）。

## 四、实战例题

### 例题 1：一段 x86-64 汇编阅读题

- 题型特征：不给可执行文件，只有 `asmcode.txt`（汇编）、`reversecode.c`（等价 C）和题目描述。
- 解题思路：
  1. 第一段循环 `ecx=19`，无变换，原样复制 19 字节数据。
  2. 中间插入一串算术 + cmp + jcc：手算 `0x2a+0x16=0x40` 与 `0x40` 相等 → 两次 `jne` 都不跳（目标是干扰分支）；`0x39-0x20=25 > 0x18` → `jg` 跳到 XOR 分支。
  3. 第二段循环 `ecx=31`，把 31 个数据段字节逐字节 `^ 0x42`。
  4. 干扰分支的 9 字节不执行，丢弃。
  5. 拼接两段并补 `\0`。
- 关键工具/脚本：`script/x86-64汇编阅读/solve.py`（复制前 19 字节、后 31 字节逐字节 XOR 0x42 并拼接）；挑战文件见 `challenge/x86-64汇编阅读/`。
- 结果：得到 flag。

### 例题 2：（同知识点变体）含条件跳转的字节变换

- 题型特征：汇编中穿插 `cmp + jne/jg` 分支选择器，数据段有多组字节。
- 解题思路：同例题 1 的流程——先定位循环与计数器，再手算分支走向，最后对执行分支的数据段做逆变换。
- 结果：得到 flag。
