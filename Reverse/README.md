## 共性方法论

- **第一步永远是查壳**：DIE 识别 PE 位数、Console/GUI、编译器、是否加壳/打包。
- **定位校验函数**：靠 `Shift+F12` 字符串窗口，用 `Enter flag:`/`Correct`/中文提示的交叉引用切入。
- **常见加密套路**：单字节 XOR、循环 XOR（注意反转/取模下标）、置换表 + XOR、RC4、ROR 派生密钥；对称运算全部可逆，优先逆推而非爆破。
- **打包识别**：overlay 见 `python3xx.dll`/`PYZ.pyz` → PyInstaller，走 pyinstxtractor → marshal/dis；壳名与节名不符（VMP0/VMP1）→ 改回 UPX0/UPX1 再脱壳。
- **动态兜底**：静态跟不动解密链时，用 Cheat Engine / 动态调试器改关键变量，让程序自己走到成功分支。
