# 静态分析基础：字符串定位与关键函数

> **所属分类**：Reverse ｜ **难度参考**：入门
> **适用题型**：无壳 PE/ELF，需要靠"提示字符串 → 交叉引用 → 校验函数"这条最短路径读懂程序逻辑的入门逆向题。

## 一、知识点原理讲解

### 静态分析在做什么

不运行程序，直接在反汇编/反编译器里阅读二进制。无壳程序拖进 IDA 后，IDA 会自动完成函数识别、流程图构建、重命名库函数，按 F5 就能得到接近 C 语言的伪代码。入门题几乎都可以纯静态解决。

### 字符串是定位锚点

程序为了和用户交互，必然在数据段放提示字符串：`Enter flag:`、`Correct!`、`Incorrect`、通关文案、错误信息。这些字符串在代码里都有一条"引用它"的指令（`push offset aEnterFlag` 或 `lea rcx, aEnterFlag`）。**顺着字符串的交叉引用往上找，就能跳到打印它的那个函数，那个函数往往就是校验/主逻辑函数。**

### 常见入口串

- `Enter flag:` / `Please input:` / `flag>`
- `Correct` / `Success` / `Wrong` / `Incorrect`
- 中文 GUI 程序的 UTF-16LE 文案（如"通关"），用 `Alt+B` 按字节搜，比 ASCII 字符串窗口更容易命中。

### 伪代码里要抓的几类结构

- `scanf/gets/fgets` 后面接 `strcmp/strcspn/memcmp`：输入长度或内容校验。
- `xor reg, imm8`：单字节异或加密，常数就是 key。
- 256 长度数组初始化 + 双层交换循环：RC4 类流密码。
- `printf("...%s...", flagbuf)`：flag 可能就拼在格式串里直接打印。

## 二、通用解题思路 / 套路

```
无壳 PE → IDA 打开，等分析完成
→ Shift+F12 打开 Strings 窗口
→ 找提示串（Enter flag / Correct / 通关）
→ 双击字符串 → X 看交叉引用 → 跳到引用它的函数
→ F5 看该函数伪代码
→ 识别校验结构（strcmp / xor / 数组比较）
→ 从 .rdata 抄密文/常量，按识别出的运算逆推
```

易错点：
- 64 位程序必须用 IDA64，32 位 IDA 打开 PE64 会乱。
- 提示串可能是 UTF-16LE（宽字符），Strings 窗口默认只列 ASCII，要在菜单里勾上 Unicode。
- 密文在 `.rdata` 段，长度要抄全，漏字节会错位。

## 四、实战例题

### 例题 1：一个本地校验、单字节异或的签到题

- 题型特征：控制台程序提示输入，DIE 报 PE64 Console、无壳。
- 解题思路：Strings 窗口里 `Enter flag: ` 一眼可见，双击交叉引用进校验函数；F5 伪代码里直接看到 `xor eax, 26h`，即输入每个字节与 `0x26` 异或后与 `.rdata` 密文比较。从数据段抄出密文，逐字节 `^0x26` 还原明文。
- 关键工具/脚本：`../assets/images/静态分析基础/check_func.png`（由提示串交叉引用进入的校验函数）、`../assets/images/静态分析基础/pseudocode.png`（校验函数伪代码，可见异或常数）。
- 结果：逐字节异或还原得到 flag。

### 例题 2：一个把答案明文写在主函数里的引导题

- 题型特征：DIE 报无壳 PE64 MSVC 控制台，主函数极短。
- 解题思路：F5 看 main，`scanf` 后接 `strcmp`，`printf` 格式串里直接拼着结果字符串——入门题常把答案以明文字符串放在代码里，静态一眼读出即可，无需任何运算。
- 关键工具/脚本：`../assets/images/静态分析基础/die_check.png`（DIE 确认无壳的报告截图）、`challenge/静态分析基础/test_your_ida.exe`（可复现样本）。
- 结果：直接从伪代码字符串读出 flag。
